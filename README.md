【5V5のTPSチームデスマッチ　Layer(れいやー)】

・コンセプト<br>

■ ゲームの仕様
エンジン　Unreal Engine  
開発コード　C++  
TPS(3人称視点)で行う、チームデスマッチ  
プレイヤーは試合中に6種のロールを任意のタイミングで変える事が可能  
(この仕様により、試合の戦況を常に変えられると考えてます)  
キーマウ・Pad対応予定　　

■ ステージ
- 荒野モチーフの「砂漠」
- 緑生い茂る「廃都市」
- 空中に浮かぶ「空中庭園」


 
■ 1. プレイヤー共通(基本)
- HP：100
- Shield：100
- OverShield：50
※OverShieldの使用 3秒間被弾無しで毎秒5ずつ自動回復※
- 移動速度 1.0
- サイフォン：30
 
 
■ 1. アタッカー
- HP：100
- Shield：100
- OverShield：50
- 移動速度：1.3
- メイン武器：ショットガン
- サブ武器：アサルトライフル
- HPを50回復する有限アイテム4つ最大4つまで持てる
- Shieldを50回復する有限アイテム3つ最大3つまで持てる
- 固有スキル：5秒以内に敵を3キルすると5秒間自身の攻撃力と移動速度(1.3から1.5)UP(発動中はスキルの重複はしない、一度使うと20秒使えない)
- 役割/特徴：最前線で撃ち合うメイン火力。正面からの突破力に優れ初心者～上級者まで幅広く使える。
 
■ 2. ヒーラー
- HP：100
- Shield：25
- OverShield：50
- 移動速度：1.0
- メイン武器：弓
- サブ武器：味方のHPを30回復できるバズーカ砲
- 固有スキル：飛行能力(飛行上限あり)
- 役割/特徴：唯一無二の「飛行能力」を使い後方から味方に回復を飛ばし、前線を維持する。
その代わりに合計体力が低く、立ち回りが求められる。
 
■ 3. レンジャー
- HP：100
- Shield：100
- OverShield：50
- 移動速度：1.2
- メイン武器：スナイパーライフル
- サブ武器：有限の毒ガス(移動速度ダウンの効果もあり)とスモーク弾　それぞれ最大4つまで持てる
- 固有スキル：自分が投げたスモークに敵が入ると3秒間自分だけに見えるアウトラインに表示(壁貫通なし)
- 役割/特徴：後方からの超長距離スナイプ。フリックエイムが最も輝く。
 
■ 4. タンク
- HP：125
- Shield：100
- OverShield：15
- 移動速度：0.8
- メイン武器：ミニガン
- サブ武器：地雷最大3つまで持て設置制限3つ
- 固有スキル：手前に小さいバリアを展開する(耐久値あり)展開中移動速度0.5になる
- 役割/特徴：盾を展開して前線を押し上げ、味方を守る要塞。
 
■ 5. ヒットマン
- HP：50
- Shield：25
- OverShield：0
- 移動速度：1.5
- メイン武器：ハンドガン(弾数2 ダメージ250 ヘッド300)
- サブ武器：なし
- 固有スキル：敵を倒すと全回復する　今後破壊可能オブジェクトを置くなら破壊できる
- 役割/特徴：高速移動で裏取りし、近接格闘や近距離武器で暗殺する特攻役。
合計HPがかなり低く、弾数も少ないためより一層立ち回りが求められるがチームに貢献しやすい
 
■ 6. エンハンサー
- HP：100
- 移動速度：1.0
- メイン武器：アサルトライフル
- サブ武器：なし
- 固有スキル：敵にダメージを与える事に自身から円状にバフのゾーンを作る、Lvが上がる度に自身の最大HPが減るが死ぬとLvが一つ戻り最大HPが戻る
チームメンバーが円の中に居ないと効果がなく一度出ると効果がリセットされる。Lv3になるとこの先いくら死んでもこれ以上下がらない
バフの詳細  
- Lv1　最大HP100　バフなし
- Lv2　最大HP75 半径キャラ2人分　効果 武器のリロード速度小UP オーバーヒート中のCT小短縮
- Lv3　最大HP50　半径キャラ2人分　効果 武器のリロード速度中UP オーバーヒート中のCT短縮は据え置き　有限アイテム30秒に1つ獲得
- Lv4　最大HP25　半径キャラ4人分　効果 自身とゾーンに居る味方プレイヤーの移動速度+0.2 武器のリロード速度大UP オーバーヒート中のCT中短縮　有限アイテム15秒に1つ獲得
- Lv5　最大HP5　 半径キャラ5人分　効果 自身とゾーンに居る味方プレイヤーの移動速度+0.3 武器のリロード速度大UP オーバーヒート中のCT大短縮　有限アイテム5秒に1つ獲得

- 役割/特徴：自身のHPを犠牲にする代わりにチーム全体がかなり動きやすくなるバッファー。
 
■ 共通システムメモ
- 武器のダメージやリロード速度等は完成してから決める

■ 作品の世界観や参考にした作品
.ベースはFortniteを参考
理由は同じUE作品であり、同じTPSシューティングで俺(開発者自身)が最も遊んだシューティングであで、
過去この作品のプロトタイプをFortniteのクリエイティブモードで作成してたため。。

2.ロールの参考にした作品は｢妖怪ウォッチバスターズ｣｢APEX Legends｣｢#コンパス 【戦闘摂理解析システム】｣
今回最初の段階で6ロール予定であり、尚且つ、キャラ依存ではなくロール依存とする観点からバスターズを参考にし
各ロールの中身をAPEXのキャラ達から、性能点はコンパスやAPEXを合わせる感じにする。

3.ゲームUIは｢VALORANT｣から
体験はほとんどして無いが、競技特化なのと、オープンキャンパスの学生スタッフとして体験した時に、はっきり見やすいと思ったので参考に。

4.ステージ 今回3ステージ予定で
荒野 廃都市 空中庭園
と考えてその中の廃都市は｢NieR:Automata｣を参考にリアル寄りのファンタジーし高低差や物陰等作る。
